# Short-Form Video Script Writer

Turn a topic or hook into a film-ready 15-60s script — hook, value beats, text overlays, storyboard and CTA.

Produces a complete script with timestamps: a hook in the first 0-3 seconds, one-line context, value beats each paired with a visual, a payoff that delivers on the hook's promise, and a CTA matched to the stated goal.

Alongside the script it writes the on-screen text overlays, a shot-by-shot storyboard (visual / spoken line / on-screen text / transition) so a creator or editor can film without guessing, platform pacing rules for TikTok versus Reels versus Shorts, retention techniques, and a word-count and duration check at roughly 150 words per minute.

## How to use it

It works with any AI client that reads a skill file — WorkBuddy, Claude Code, Codex, Cursor — or with no
client at all:

1. **As a skill.** Put `SKILL.md` where your client looks for skills (usually a folder named after the
   skill, containing `SKILL.md`).
2. **As a prompt.** Paste `SKILL.md` into a conversation with any capable model and then ask your question.
